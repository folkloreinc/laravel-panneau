# Protocol schemas

Copies of the files generated by [`@panneau/protocol`](https://github.com/folkloreinc/panneau-js/tree/v5.x/packages/protocol), used by the tests to check what the package sends:

- `definition.schema.json`: the JSON Schema of the definition;
- `openapi.json`: the OpenAPI 3.1 document of the HTTP API.

`VERSION` holds the `panneau-js` commit they come from. The CI's conformance job runs the conformance kit of the same commit. To update them:

```bash
tests/protocol/update.sh        # latest v5.x
tests/protocol/update.sh <ref>  # a branch, tag or commit
```
